## 🚀 Terminal Missionen – Das Highlight

Mein größtes Projekt der letzten Monate: **Terminal Missionen** – eine interaktive Lernplattform für Linux, Docker und Git.

**Was es kann:**

- Echtes Linux-Terminal im Browser, keine Installation nötig
- 11 Missions in 3 Kategorien: Linux, Docker, Git
- CTF-Challenges für Fortgeschrittene
- Schritt-für-Schritt Validierung mit Hints

**Für wen:**

- FISI-Azubis und Umschüler
- DevOps-Einsteiger
- Alle, die Linux lernen wollen

[→ Terminal Missionen ausprobieren](/projekte/terminal-missionen/app/)

### Die Technik dahinter

Falls du dich fragst, wie ein Terminal im Browser funktioniert:

- **WebContainer API:** WebAssembly-basierte Linux-Runtime
- **Custom Node.js Shell:** 25+ Linux-Befehle implementiert
- **xterm.js:** Terminal-Rendering
- **React 19:** Interaktive UI

Mehr dazu in meinem [WebContainer Deep Dive](/blog/webcontainer-linux-im-browser/).

## ⚡ Tech-Stack Upgrade

Unter der Haube wurde einiges modernisiert:

| Vorher     | Jetzt          |
| ---------- | -------------- |
| Astro 4    | **Astro 5**    |
| React 18   | **React 19**   |
| Tailwind 3 | **Tailwind 4** |
| Node 18    | **Node 20**    |

**Was bringt das?**

- Schnellere Build-Zeiten
- Bessere Performance
- Neue React 19 Features (Actions, useOptimistic)
- Tailwind v4 CSS-Native Approach
