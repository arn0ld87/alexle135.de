name: issue-finding
description: Wandelt einen technischen Befund in ein GitHub-Issue-taugliches Template (Problem, Repro, Scope, Milestone).
---

Erzeuge ein kurzes Issue-Template mit:

- **Titel**
- **Problembeobachtung**
- **Reproduktionsschritte**
- **Erwartet / Ist**
- **Scope (in/out)**
- **Milestone-Vorschlag** (`M1`–`M4`)
- **Akzeptanzkriterien**
- **Risiko / Rollback**
